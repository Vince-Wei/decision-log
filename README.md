# decision-log

> 决策记录：半年后有人问"当初为什么这么定"，这里就是答案。

## 简介

这里记录那些不好拍板、或者拍了之后影响挺久的决定。重点不是记结论，而是记**当时的处境和取舍**——结论会被记住，理由不会。

## 目录结构

| 目录 / 文件 | 说明 |
| --- | --- |
| `accepted/` | 已生效的决策 |
| `superseded/` | 被后续决策推翻的，保留原文并注明被谁取代 |
| `pending/` | 待定中的决策草案 |
| `index.md` | 决策总览，按时间或主题索引 |

## 决策格式

一份决策六段，缺哪段就说明还没想清楚：

```markdown
# [决策主题] YYYY-MM-DD

- 状态：已生效 / 待定 / 已推翻
- 背景：当时面临什么情况，为什么必须现在决定
- 选项：考虑过哪几个方案（至少两个，只有一个说明没得选）
- 决定：最终选了哪个
- 理由：为什么选它，放弃了什么
- 影响：后续需要注意的约束条件
```

## 写作原则

- 至少写两个被考虑过的选项，只列一个方案的那不叫决策
- 理由要写"放弃了什么"，只写优点的是事后合理化
- 决策被推翻时不要删，移入 `superseded/` 并注明取代它的新决策，删了就等于假装没走过弯路
- 只记录有后续影响的决定，午饭吃什么不用写
